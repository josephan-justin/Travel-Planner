# Travel Planner

Travel Planner is a full-stack web application that helps users create and manage personalized travel plans based on their preferences.

## Features

- AI-powered personalized travel plan generation
- Google OAuth authentication
- Create, view, update, and manage travel plans
- Export travel plans as PDF
- Personalized travel planning based on user preferences

## Tech Stack

### Frontend
- React.js

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL
- Sequelize

### Authentication
- Google OAuth

### AI
- AI-powered travel plan generation

## How It Works

1. Users sign in using Google OAuth.
2. Users provide their travel preferences and requirements.
3. The application uses AI to generate a personalized travel plan.
4. Users can view and manage their travel plans.
5. Travel plans can be exported as PDF.

## Main Functionality

### Travel Plan Management

Users can:
- Create travel plans
- View their travel plans
- Update travel plans
- Manage their existing travel plans
- Export travel plans as PDF

### AI Travel Planning

The application uses AI to generate personalized travel plans based on the user's preferences, making the planning process more convenient.
